# yoxi 城市夥伴(City Companion)

> 不搭車,也有理由每天打開 yoxi。

本專案為 **2026 和泰 AI 黑客松**提案,團隊「超級聰明特攻隊」。企業挑戰題目為「yoxi:不搭車,也打開 yoxi —— 打造高頻互動的 AI 出行夥伴」,本 repo 整理 yoxi 城市夥伴的提案簡報、系統架構、介面流程與介面預覽。

## 💡 專案概述

**核心問題**:叫車只在有出行需求時才被打開,開啟頻率低、黏著度有限。

**核心價值主張**:每天一張 5 秒簡報、每週一件城市小事、長期一位記得你的夥伴;該叫才叫。

**目標對象**:想在不叫車時也掌握出行與城市資訊的 yoxi 用戶,包含通勤族、城市探索者、輕鬆互動族、夜間返家者。

### 解決方案設計重點

1. **日・週・長期三種節奏**:每日城市簡報、每週城市探索、長期角色夥伴,由同一位吉祥物角色遞送。
2. **移動記憶 + 城市脈搏驅動個人化**:移動記憶由用戶自行檢視、編輯、清除;城市脈搏為 yoxi 獨有資料。
3. **誠實出行建議與微轉換增量驗證**:該叫才叫(叫車、步行、捷運、晚點再叫),並以對照組證明真實增量。

### AI 應用方法

原則:**規則為主,AI 用在刀口上**。簡報以規則組版,只有一句走 LLM;不為轉換而誘導。

| 技術 / 工具 | AI 的關鍵角色 |
| --- | --- |
| LightGBM | 預測各區域各時段的需求與壅塞(批次預先計算) |
| 規則引擎 + 模板 | 簡報組版與出發建議邏輯 |
| Claude Haiku 5.5 / Sonnet 5.5 | 簡報個人化一句、角色對話;複雜行程生成 |
| pgvector + 護欄 | POI、活動與角色記憶檢索;內容與安全稽核 |

### 預期效益(皆為目標值,非實測)

- 簡報開啟率 > 35%
- 簡報 → 叫車轉換率 > 5%
- 探索 → 叫車轉換率 > 8%
- 角色每日開啟率 +20%
